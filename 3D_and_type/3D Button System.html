An alternative component language built on the same palette and type. Physical depth, perspective, and dimensional form — where the 2D system uses light, this one uses volume.

01 MECHANICAL EXTRUDE — Click to press
Primary hierarchy — three tiers

The face is a physical surface with a light source at top: specular highlight along the top edge, shadowed underside. Below the face, layered box-shadows build a visible side wall. Click — the face presses flush with the floor as the wall collapses to 0.

Full palette — hover each, then click
02 CHROME BEVEL — Polished dark metal
Light source top-left · Inset edge highlight

A single-pixel inset shadow on the top-left edge catches the light; the bottom-right stays in deep shadow. The illusion of a beveled metal plate. Active state inverts the bevel — pressed inward, like a key bottoming out.

03 PRISMATIC TILT — Move cursor slowly across
CSS perspective · Mouse-tracked tilt · Iridescent film coating

Mouse position drives CSS perspective rotation (rotateX + rotateY). A specular sheen overlay shifts with the tilt, and a conic-gradient film layer blends prismatic color across the surface. Snaps back with an ease-out spring on leave.

04 LIQUID GLASS — Frosted depth
Backdrop blur · Top-edge specular · Float on hover

A frosted glass face: backdrop blur for depth, a top-edge gradient for the specular catch, a bottom gradient for the colored reflection. Floats 3px upward on hover; compresses on active. Best over textured or gradient backgrounds.

05 NEON EXTRUDE — Dark face, glowing walls
Wire border · Colored side walls · Text-shadow glow

The face is void — depth comes entirely from the glowing border and the colored shadow-wall below it. Text-shadow glow matches the edge color. Hover intensifies the halo. Press collapses the wall, same mechanic as the mechanical extrude.
