01 IMPLEMENTATION

STEP 1 — ADD THE STYLESHEETS

<!-- existing -->
<link rel="stylesheet" href="colors_and_type.css">

<!-- add immediately after -->
<link rel="stylesheet" href="sy-3d.css">

STEP 2 — ACTIVATE BUTTON OVERRIDES

<!-- add sy-3d to body — keeps the 2D system on pages without it -->
<body class="sy-grain sy-3d">

STEP 3 — ADD INTERACTIVE EFFECTS

<!-- bottom of body, after all content -->
<script src="sy-3d.js" defer></script>

<!-- re-init after dynamic content insertion -->
<script>SY3D.init()</script>

The type token fixes in sy-3d.css apply globally as soon as the file loads — no class needed. Button overrides only fire inside .sy-3d. Cards, inputs, badges, and toggles are opt-in by class name on individual elements.

02 TYPE TOKENS — FIXED HEX — active globally
These two tokens change. Everything else in colors_and_type.css is untouched.

--sy-fg-2 Body paragraphs, descriptions, secondary content. Was rgba(240,242,255,0.65). #c8cadc  ↑ lifted
--sy-fg-3 Section labels, metadata, timestamps, captions. Was rgba(240,242,255,0.32). #7a7c94  ↑ lifted
--sy-fg-4 Dividers, ghost borders. Unchanged — this is structural, not text. rgba(…, 0.06)  (unchanged)

08 SEMANTIC PLACEMENT RULES — when to use what
Each component type maps to a specific semantic role. These are not style choices — they are meaning choices.
PERSPECTIVE CARDS
Enter · Choose · Connect
Only on surfaces that have something on the other side — buildings you enter, tiers you choose, connectors you activate, archetypes you become. The tilt says: depth exists here. Never on static info displays or sidebar nav items.
EXTRUDED BADGES
Status · Identity · State
Color is semantic — not decorative: green = active/live/go, cyan = informational/advisory, gold = premium/earned/founding, red = warning/danger. Never use flat text where a badge belongs, and never use a badge where flat text is sufficient.
PHYSICAL TOGGLES
Binary Mode Switches Only
Reserved for choices where the two states represent genuinely different modes — billing cycle, avatar/text mode, audio on/off, sync active/paused. The sliding thumb is a physical commitment. Not for filters, preferences, or anything with more than two states.
DEPTH INPUTS
Conversation · Identity
The sunken well says: what you put here matters. Reserved for FY conversation inputs, studio naming, email capture, subscribe commitment. Not for search, filters, or utility inputs. The FY chat input is the primary instance — all others inherit their meaning from it.
ANIMATED GIFS
Singular Earned Moments
Each GIF fires once at a specific moment — never on a loop, never as decoration, never stacked. Velvet rope = access granted. Trophy = achievement unlocked. ID card = identity being established. Shutter = system thinking. Their rarity is the design.
